# The Happy Store — Shopify OS 2.0 Theme

A custom, responsive Shopify Online Store 2.0 theme matching the supplied Happy Store references.

## Native Shopify architecture

This is a real Shopify Liquid theme, not a standalone HTML website. It uses:
- JSON templates
- Liquid sections and blocks
- Header/footer section groups
- Theme Editor settings
- Shopify products and collections
- Shopify menus
- Shopify cart, search, customer accounts and checkout
- Image pickers instead of hard-coded product/hero images

Merchants can therefore change content, images, links, collections, colors, fonts and section order from **Shopify Admin → Online Store → Themes → Customize**.

## GitHub

Upload the CONTENTS of this folder to the root of a GitHub repository. Do not nest the theme inside another folder.

Then in Shopify:
**Online Store → Themes → Add theme → Connect from GitHub**

Select the repository and branch.

## Before publishing

1. Create your Shopify navigation menus.
2. Create collections such as Men's Fashion, Women's Fashion and Toys & Gadgets.
3. Add your real products and images.
4. Open Customize and replace demo copy/images/collections.
5. Test cart, checkout and mobile layout.
6. Install/configure apps for advanced reviews, wishlists, filters, analytics, etc.

## Important

The reference screenshots are used as the visual design target. Product/hero images are deliberately editable through Shopify image pickers and Shopify product data instead of being hard-coded into the theme.
